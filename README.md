# 江戸幕府末期の銃撃戦.io

ブラウザで遊べる撃ち合いゲームです（Three.js + Socket.IO）。

## 遊び方（PC）
1. `npm install`
2. `npm run server`（ターミナル①：ゲームサーバー、ポート3000）
3. `npm run dev`（ターミナル②：画面、http://localhost:5173）

操作：WASD移動 / Spaceジャンプ / マウス視点 / クリック射撃 / 1〜7武器 / R リロード / Tab スコア / O 設定

## 武器
ナイフ（標準・カランビット）、ピストル、リボルバー、サブマシンガン、アサルトライフル、スナイパー、ショットガン

## スキン
武器ごとに選べる16種類（設定の「スキン」）。

## デプロイ（Fly.io）
`package-lock.json` は必ず一緒にアップロードしてください（Dockerのビルドで `npm ci` を使うため、無いと失敗します）。
```
fly apps create 変えた名前   # fly.toml の app も同じ名前に
fly secrets set ADMIN_KEY=長い文字列
fly deploy
```
必要なら `ALLOWED_ORIGINS`（カンマ区切り）で、接続を許可するドメインを指定できます。

## 投票キック
3人以上で、他のプレイヤーを投票で切断できます（1件ずつ、30秒、対象以外の過半数が賛成で成立）。管理者は対象になりません。切断であり、BANではありません。

## テスト
`npm test`（ルール・設定の単体テストと、実際にサーバーを起動して複数のクライアントで動かす統合テスト）

## 管理者
設定（O）の「管理者キー」に `ADMIN_KEY` と同じ文字列を入れると、管理パネル（P）が使えます。管理パネルでは、キック、マップ変更、お知らせ、操作ログの確認ができます。

## 不正対策
- 移動・射撃・当たり判定はすべてサーバー側で計算します
- 入力の頻度・値の範囲を検査します
- エイムボットの疑いは自動で検知し、段階的に処分します（1時間→2時間→5時間→10時間→永久BAN）
- 処分の単位は、ブラウザごとの識別子です。同じIPの別の人を巻き込まないよう、IPは同じ回線から3つ以上の識別子が処分された時だけ止めます
- 管理者キーはブラウザに保存しません（ページを開くたびに入力します）
- 処分の記録（BAN）は `DATA_FILE`（既定：`data/penalties.json`）に保存され、再起動後も残ります

### 処分の記録を消さないための設定（Fly.io）
```
fly volumes create penalty_data --size 1 --region nrt
```
fly.toml に次を追加し、`[env]` に `DATA_FILE = "/data/penalties.json"` を書きます。
```
[[mounts]]
  source = "penalty_data"
  destination = "/data"
```
